# ElectronShell 整体规格

> 最后更新：2026-10-20
> 本文描述系统**做什么、为什么**，不涉及实现细节（技术选型见 `TECH.md`，实现见 `ARCHITECTURE.md` 与各模块 `plan.md`）。

---

## 1. 系统定位

ElectronShell 是一个运行在 HarmonyOS / OpenHarmony 设备上的**极简浏览器测试壳**。它的价值不是替代系统浏览器，而是：

1. 用最小可用的界面验证 **Electron 内核在鸿蒙设备上的渲染、网络、多进程与输入能力**；
2. 为后续基于 Electron 的鸿蒙应用提供一个**可直接复用的启动壳**（全屏容器 + 地址导航 + 本地记忆）。

目标用户：

| 角色 | 诉求 |
|------|------|
| 内核/框架开发者 | 快速验证 Electron 在鸿蒙上的行为（站点兼容性、Canvas/WebGL、多窗口、输入法） |
| 应用开发者 | 拿一个能跑通的壳工程作为起点，替换成自己的站点或前端工程 |
| 测试人员 | 按用例在真机上验证内核表现并留存证据 |

## 2. 核心能力（用户故事）

| 编号 | 用户故事 |
|------|---------|
| US-001 | 作为用户，我打开应用就能看到上次访问的网页，并且它铺满整个屏幕 |
| US-002 | 作为首次使用的用户，应用直接给我一个地址输入框，我可以立刻开始浏览 |
| US-003 | 作为用户，我随时能点左下角的悬浮按钮唤出地址栏 |
| US-004 | 作为用户，输入网址并确认后地址栏自动收起，不遮挡内容 |
| US-005 | 作为用户，我在手机竖屏、平板、PC 上都看到合理的布局 |
| US-006 | 作为用户，我点击网页里的链接（含新窗口链接）都在当前页面打开，不会弹出一堆窗口 |

## 3. 功能域

### 3.1 沉浸式展示

- 应用以全屏方式呈现，浏览内容覆盖系统状态栏与底部导航条所在区域；
- PC/2in1 形态下窗口最大化，不显示应用标题栏与窗口按钮；
- 无导航栏、无标签页、无工具栏，最大化浏览区域。

### 3.2 地址导航

- 常驻一个左下角圆形浮动入口；
- 点击后在屏幕底部展开地址输入面板（含输入框、「前往」、「✕」）；
- 输入支持省略协议（自动补 `https://`）；
- 非法输入就地提示，不发起跳转；
- 确认成功后输入面板自动收起。

### 3.3 访问记忆

- 记录最后一次**确认成功**的地址；
- 下次启动自动加载该地址；
- 若历史记录不可用（被破坏或非法），按「无记录」处理，不阻塞使用。

### 3.4 多形态适配

- 覆盖手机（`default`）、平板（`tablet`）、PC（`2in1`）、电视（`tv`）；
- 依据窗口宽度分三档布局，并在横竖屏切换、窗口拉伸、软键盘弹出时实时重排。

### 3.5 单窗口浏览

- 网页中的新窗口请求在当前窗口打开；
- 外部协议交由系统处理。

## 4. 非功能要求

| 类别 | 要求 |
|------|------|
| 性能 | 浮动入口点击到面板展开 ≤ 100ms；地址确认到内核开始加载 ≤ 1s |
| 可靠性 | 窗口能力/存储/文件写入任一失败都不得导致崩溃，功能可降级 |
| 兼容性 | API 20+；四类设备形态；横竖屏 |
| 可观测性 | 关键路径（状态文件路径、导航序号、加载成功/失败）必须有日志 |
| 安全 | 内核侧禁用 Node 集成、开启上下文隔离；不新增未声明理由的敏感权限 |
| 可维护性 | 界面、服务、纯逻辑分层；同一 UI 逻辑只实现一次 |
| 可复现性 | 资源和签名材料可通过脚本从源工程重新装配，不依赖人工拷贝 |

## 5. 系统边界

### 5.1 范围内

- 全屏宿主窗口与沉浸式设置；
- Electron 内容承载与生命周期托管；
- 地址输入、规整、校验、导航；
- 最后一次地址的本地持久化与启动恢复；
- 响应式布局；
- 内核侧窗口与导航策略（单窗口、外链托管）。

### 5.2 范围外

| 不做的内容 | 原因 |
|-----------|------|
| 多标签页 / 历史记录 / 书签 | 壳的定位是内核验证，不是完整浏览器 |
| 下载管理 / 密码填充 / 隐私模式 | 同上 |
| 前进 / 后退 / 刷新按钮 | 可用系统/网页自身的交互，暂不做 UI |
| 账号登录（`pages/Login` 仅为上游保留能力） | 非本需求 |
| 应用商店上架、正式发布签名 | 本工程为调试用途 |
| Electron 内核自身的编译 | 直接使用 v37.2.3 官方产物 |

## 6. 关键质量属性场景

| 场景 | 期望 |
|------|------|
| 用户第一次安装启动 | 3s 内看到可输入的界面（空页面 + 输入面板） |
| 用户重启应用 | 直接回到上次站点，无需任何操作 |
| 用户输错地址 | 1 帧内出现错误提示，页面不发生任何跳转 |
| 用户在 PC 上把窗口从全屏缩到半屏 | 输入面板与按钮自动切换紧凑档，不出现横向滚动或文本截断 |
| 网页请求新窗口 | 不产生新系统窗口，页面在当前区域替换 |
| 内核导航失败 | 回到空页面，日志可见失败原因 |

## 7. 词汇表

| 术语 | 含义 |
|------|------|
| 壳（Shell） | 承载 Electron 内容的鸿蒙应用，只提供容器与最小导航能力 |
| 浏览器组件 | 由 Electron 渲染的网页区域（对应 `BrowserWindow`） |
| 状态文件 | ArkTS 与 Electron 之间的导航契约文件 |
| 沉浸式全屏 | 应用绘制区域包含系统栏区域，且系统栏被隐藏 |
| 紧凑/常规/宽屏档 | 按窗口宽度划分的三档布局（<600vp / 600~839vp / ≥840vp） |
